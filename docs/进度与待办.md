## 二、故意保留日文的地方

主线 2 有 **5 条**台词讲的是「给书本按日文五十音顺序排序 / 查找」，其中的音序被有意保留日文，译成中文反而破坏逻辑：

| 序号 | 内容片段 |
|---|---|
| 727 | `『ほ』…『あ』` |
| 1029 | `『あ』『い』『う』` |
| 1329 | `『の』` |
| 1705 | `『の』` |
| 1960 | `『の』…『あ』…『ん』` |

自动校验会把这些报成「残留日文」，**属于正常**。
